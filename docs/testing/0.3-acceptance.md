# 0.3 incremental acceptance criteria
- Existing assessment, reporting, intelligence and remediation tests continue passing.
- Unexpired ownership challenges are reusable, recoverable after reload and tenant scoped.
- GitHub helper accepts only owner/repository identifiers, creates a prefilled file URL, and never treats repository access as domain ownership.
- Revocation invalidates outstanding challenges. No challenge reuse extends validity.
- UI shows verification instructions, expiry and explicit launch prerequisites; checkbox is visible.
- Optional Firebase identity linking requires an existing authenticated, verified AEGIS account and recent verified Firebase identity. No email-based account takeover. Firebase login never grants asset ownership or deployment rights.
- Disabled Firebase mode fails closed. Invalid/revoked/stale identity rejected. External live integration requires operator credentials and remains blocked until configured.
- Production deployment connectors, MFA step-up and automated patch delivery remain blocked until independently tested; no implicit production write capability.
